# Examples

These are fictional teaching examples. Numerical or factual statements below may be used in a real project only when confirmed by that project's data.

## An empty English hero

Before: “Unlock the future of effortless growth. Not just a platform, your competitive edge.”

After, if supported: “Track incoming requests and assign each one to a teammate.”

Why: C05, C07, C09. The revised line identifies a concrete job. It makes no invented performance claim.

## An empty Russian hero

Before: «Комплексные инновационные решения для вывода вашего бизнеса на новый уровень».

After, if supported: «Разрабатываем сайты с каталогом, заявками и оплатой».

Why: C05 and C08. Use the capabilities the business actually offers. Omit payment if it is not part of the service.

## Preserving Russian grammar

Before editing: «Наша задача — сделать заказ понятным».

After: keep it if it fits the context. The dash is doing grammatical work. If the entire sentence adds nothing, edit its meaning instead of deleting a character.

Why: C18. Typography rules are not a substitute for language understanding.

## An honest editorial edit

Before: “I think we need one more trial. The initial results look promising, highlighting our commitment to a transformative future.”

After: “I think we need one more trial. The initial results look promising.”

Why: C02, C11, C12, C16. Preserve the actual uncertainty and remove the empty interpretation without inventing evidence.
